# Languages: English · Finnish · French

**Scope:** every public page, every form, every app screen, validation messages, emails/notifications, and CMS content.

| Layer | Approach |
|---|---|
| UI strings | `packages/i18n/src/messages/{en,fi,fr}.json` (107 keys so far), loaded with `next-intl`. `pnpm i18n:check` fails the build on a missing, empty or mismatched-placeholder translation. |
| Public routing | `www.afrofoot.club/en`, `/fi`, `/fr` (locale prefix, `hreflang` tags, sitemap per language). First visit: `negotiateLocale(Accept-Language)`, then the visitor's choice is remembered. |
| App routing | Locale follows `profiles.locale` (changeable in the account menu); cookie for signed-out screens. |
| CMS content | English in the normal columns; Finnish and French in `translations` jsonb (`{"fi": {"title": "..."}}`), validated by the database. Missing translation → falls back to English, and the editor shows "FI missing / FR missing" badges. |
| Enums (roles, statuses, positions) | Stored as language-neutral codes; labels come from the message files (`role.coach`, `status.paid`, …). |
| Formats | `Intl` with `en-GB`, `fi-FI`, `fr-FR`, time zone Europe/Helsinki, currency EUR. |
| Forms | Contact / join requests store the visitor's `locale` so staff reply in the right language. |
| Notifications | Announcements can carry fi/fr translations; each recipient gets their profile language. |

**Design consequences:** Finnish text is longer (allow wrapping, avoid fixed-width buttons); long compound words need `hyphens: auto` and `lang` on `<html>`.
**Process:** new UI text is added to `en.json` first; fi/fr are added in the same change (checked in CI). Translations of club-specific wording (tagline, values) should be validated by native speakers of the club.

## Arabic (right-to-left)
`ar` is the fourth locale. `dirOf(locale)` sets `<html dir>`; layouts use logical utilities (`ms-*`, `me-*`, `text-start`); the pitch diagram is always LTR. Digits stay Western (`ar-u-nu-latn`). Fonts: Saira (display, matches the logo lettering) and Cairo (Arabic). Message parity check covers en/fi/fr/ar (152 keys).
